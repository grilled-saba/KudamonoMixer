# KudamonoMixer

- フルーツをスライスして合体させ、より上位のフルーツを目指していく2Dパズルゲーム  
- Unity 6000.0.64f1 / URP / ML-Agents を使用
- 推奨解像度：900×800（Windowed モード）

## 遊び方
- 左ドラッグ：飛んでいるフルーツをスライス 
- 右クリック：フルーツを弾いて軌道を変える ・ 爆弾を回収
- スペースキー ・ 発射ボタン：フルーツを発射 

- ドリアンを目指そう
- ミキサーからフルーツがはみ出るとゲームオーバー

## モード

- シングルプレイ：ドリアンを作れば勝利
- AI バトルモード：先に2つのドリアンを作った方が勝利（ML-Agentsによる推論）


## 使用ツール

- Unity 6000.0.64f1
- Unity ML-Agents
- URP (Universal Render Pipeline)
